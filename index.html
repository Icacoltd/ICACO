How we work

Root, branch, growth

The same sequence, every engagement — named after the shape the mark is drawn from.

Root

Understand what's actually true

Before recommending anything, we get underneath the presenting problem — the numbers, the incentives, the history — so the decision is built on what's real rather than what's assumed.

Branch

Lay out the real options

Most decisions look binary and aren't. We map the genuine set of paths available, with the trade-offs and second-order consequences of each made explicit.

Growth

Commit, and build the plan to move

A recommendation on its own changes nothing. We leave every engagement with a sequenced plan, owners, and the milestones that tell you if it's working.
